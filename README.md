# The Ivory Flow

A luxury lifestyle and interior design showcase website built with HTML,
CSS, and JavaScript. The project presents curated interiors, handcrafted
furniture, and a refined visual experience through an elegant,
editorial-style landing page.

## Overview

**The Ivory Flow** is a front-end website concept focused on quiet
luxury, thoughtful design, and curated living. Visitors can explore an
interior design lookbook, view a featured furniture piece, learn about
the design and craftsmanship process, and find contact information.

## Features

-   **Editorial hero section** introducing the brand and its design
    philosophy.
-   **Lookbook gallery** showcasing interiors, ceramics, textiles,
    furniture, bedrooms, and architectural details.
-   **Featured product section** highlighting the Maren Lounge Chair,
    including its materials, dimensions, lead time, and origin.
-   **Craftsmanship timeline** describing the sourcing, design, craft,
    and delivery stages.
-   **Studio story section** presenting the brand's workshop story.
-   **Contact section** with email and contact details.
-   **Responsive navigation** with desktop and mobile navigation
    layouts.
-   **Interactive visual effects** and page interactions powered by
    JavaScript.
-   **Custom typography** using Google Fonts.

## Getting Started

No build tools or package installation are required. This is a static
front-end project.

### 1. Clone the repository

``` bash
git clone https://github.com/Armaan-2005/project.git
```

### 2. Open the project folder

``` bash
cd project
```

### 3. Run the website

Open `index.html` in your browser.

For a local development server, you can use the VS Code **Live Server**
extension, or run:

``` bash
python -m http.server 8000
```

Then visit:

``` text
http://localhost:8000
```

## Customization

-   Update the page content and sections in `index.html`.
-   Modify colors, typography, layouts, and responsive styles in
    `tooplate-ivory-style.css`.
-   Customize navigation and interactive behavior in
    `tooplate-ivory-script.js`.
-   Replace or add images in the `images/` directory. Keep image
    filenames and paths in `index.html` in sync.
